# Security model

<!-- trace:v1 id=doc.security-model work=WORK-CO-Q8Z1HJJJ satisfies=REQ-CO-T692W95P -->

## Trusted

- carter-omp source and configuration
- GitHub webhook secret
- Configured authorized GitHub user IDs (`CARTER_OMP_AUTHORIZED_USER_IDS`)
- GitHub App private key holder (github-proxy container only)
- `TriggerContext` generated by host routing code
- Capability policy generated by host routing code

## Untrusted

- The internet, issue/PR authors, commenters, reviewers
- Issue titles/bodies, comments, PR bodies/diffs, reviews
- Repository source files, repo instructions (`AGENTS.md`, rules), READMEs
- Shell/test output, compiler output, CI logs, commit messages
- Downloaded dependency output, model output

## Invariant

```text
UNTRUSTED GITHUB EVENT → verify signature → repo ID → actor ID →
exact trigger? → actor authorized? → fixed capabilities → persist →
enqueue → OMP may run → host tools enforce → proxy enforces
```

The LLM never decides authorization, trigger validity, identity, push/PR
rights, `main` mutation, check bypass, or cross-issue/repo actions.

## Threats and controls

| Threat | Controls |
|---|---|
| Prompt injection | `<authorization-boundary>` prompt section; capabilities fixed by host; unexposed tools; proxy re-checks |
| Unauthorized compute trigger | Strict router: only exact authorized label/mention queues; everything else `state=skipped` before the queue |
| Unauthorized GitHub write | `bindings.require()` on every side-effect tool; proxy enforces repo/thread/branch/action; App installation tokens scoped per repo |
| Cross-repo confused deputy | `repository.id` allowlist at router + proxy; push/PR tools pin trigger repo |
| Cross-issue confused deputy | Comment/label tools bound to current thread; push requires workspace branch |
| Credential exfiltration | Expanded `_SCRUBBED_ENV_KEYS`; credential sidecar; agent env never holds PAT/App key/webhook secret/HMAC |
| Malicious test/package code | Dependency install + tests + agent bash share the credential-free sandbox; non-root runner; dropped capabilities |
| Network pivoting | Orchestrator/runner/proxy segmentation; per-repo network policy; RFC1918/link-local/metadata blocks (operator config) |
| Replayed webhook | `X-GitHub-Delivery` dedup; one-shot trigger consumption; replay reuses stored `TriggerContext`, never re-authorizes |
| Stale labels | Trigger label consumed on accept (removed, replaced by `carter-omp:running` → `done`/`needs-input`/`failed`); state labels never trigger |
| Capability escalation | Model cannot request caps; subagents inherit parent caps; release caps expire with the run |
| Branch/ref injection | `carter-omp/*` namespace enforced; no force push; expected-HEAD, clean-tree, identity, remote-URL guards retained |
| Git remote substitution | HTTPS-only, no embedded credentials, no helper tricks, no refspec injection, expected-repo checks retained |

## Fail-closed rules

Missing sender, ghost sender, missing actor/repo ID, unknown installation,
unknown trigger, bad/expired capability token, unknown repo, tool target
mismatch → deny. Never substitute "probably Carter".
